# FEA Studio Examples

| File | Content |
|---|---|
| `example1_bracket.fea` | 3D-printed PLA bracket: orthotropic shell + infill, Tsai-Wu criteria, cylindrical pin support, bearing load, gravity, 1000 h / 30 °C creep, 0–200 N fatigue. |
| `example2_assembly.fea` | Steel base with column (two a4 fillet welds) and 3D-printed PLA arm with two M6 preloaded bolts: welds, bolts, cylindrical anchor support, bearing/remote loads, gravity, steady-state/transient thermal, thermal stress, local mesh refinement, dual-channel fatigue, creep. |
| `example3_flange.fea` | Flanged pressure pipe joint with blind cover: 4× ISO 4017 M10×45 8.8 bolts with washers/nuts, VDI 2230 preload, 2.5 MPa internal pressure, 10 kN axial pipe tension, joint separation/leakage checks. |
| `example4_jib.fea` | Welded S355 crane jib: anchor plate with 4 bolt holes, lifting arm with 5000 N pin load, stiffening gusset, 5× a4 fillet welds (EN 1993-1-8 and IIW fatigue), 800 N lateral load, gravity. |
| `example5_heat_sink.fea` | Finned aluminum heat sink with stainless power module: 40 W heat dissipation, h = 15 W/(m²·K) convection to 25 °C air, steady-state and transient (10 min) heating, thermal expansion mismatch stress. |
| `example6_hall_frame.fea` | CAD-free beam portal frame (`frames.py`): standard EN sections (HEA/IPE/UPE/CHS), snow, wind, modal analysis, EN 1993-1-1 code check. |
| `example7_pcb_dynamics.fea` | PCB test fixture dynamics: aluminum bracket on shaker table, FR-4 PCB on 4 standoffs, 80 g transformer point mass (rigid coupling, rotary inertia), 1.5 kg/m² component surface mass; 20 modes, 3% damping, 1 g harmonic base excitation (Y axis, 10–2000 Hz), IEC 60068-2-64 random vibration ASD curve. |
| `example8_crank.fea` | Slider-crank mechanism: rigid CAD bodies, kinematic joints, piston guide, 3000 RPM motor, 3000 N gas force, kinematic simulation, peak load extraction transferred to FEA (inertia relief stress analysis of connecting rod). |
| `example9_base_contact.fea` | Bolted column base: 2× M10 8.8 bolts, frictional surface contact, nonlinear step sequence: preload → 20 kN tension → 3 kN shear; contact pressure, gap opening, contact status. |
| `example10_bracket_topology.fea` | Topology optimization (BESO): solid 160×90×12 mm S235 steel plate design space, 2 wall mounting bolts, 4 kN eye load; 40% volume target, R = 8 mm filter, 4% evolutionary rate, protected selections; includes baseline linear statics and optimized shape (STL export). |
| `*.step` | Example CAD geometries (generated by `geometry.py`). |

In the GUI: **Help → Example Walkthrough** opens a working copy of any example in `%LOCALAPPDATA%\FEAStudio\ukazky`.

## Regenerating Examples

```bash
.venv\Scripts\python.exe -m examples.create            # Setup only (writes to examples/)
.venv\Scripts\python.exe -m examples.create --solve    # Solve all studies and write results
.venv\Scripts\python.exe -m examples.create --only 3 --solve --out custom_folder
.venv\Scripts\python.exe -m examples.frames             # Example 6 (frame)
```

Approximate solve times with `--solve` (8 cores / 16 threads): Example 7 ~1 min, Example 8 ~20 s, Example 9 ~3–5 min (nonlinear contact), Example 10 ~3 min (41 ccx iterations on one mesh).

## Test Problems (`user_tests/`)

`T1_cantilever` through `T10_crank_r20_l80` provide baseline STEP geometries with known analytical benchmarks (corresponding to verification problems V1, V3, V4/T2, V7, S2, W1, P1, Y2, K1, K4, MB1). Regenerate test models via:
`.venv\Scripts\python.exe -m examples.user_tests`.
