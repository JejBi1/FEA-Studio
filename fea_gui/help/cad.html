Export from CAD (SolidWorks, Inventor, Fusion…)

How to get a model from CAD into FEA Studio: export to STEP with the right settings, or for Fusion, SOLIDWORKS and Inventor use the Send to FEA Studio button, which also transfers the part materials.

Quick overview

CADEasiest wayMaterials transferred?
Autodesk Fusionadd-in – the Odeslat do FEA Studia (Send to FEA Studio) button in the FEA STUDIO panelyes
SOLIDWORKS 2020–2025FEAStudio_Export macro (toolbar button)yes
Autodesk Inventor 2021–2026FEAStudio_Export iLogic rule (ribbon button from 2023)yes
others (Solid Edge, Creo, CATIA, NX, Onshape, FreeCAD, Rhino…)manual STEP AP214 export → drag it onto the FEA Studio window or Send to → FEA Studiono – assign them in Materials

The SOLIDWORKS macro and the Inventor rule have not yet been tried in real SOLIDWORKS or Inventor (only their logic was verified outside CAD). On first use check that the STEP file was saved and FEA Studio opened; if not, use the manual export.

Send toRight-click the STEP → Send to → FEA Studio (Windows 11: Show more options, or Shift + right-click). The installer creates the shortcut.
  • Shortcut, Send to or a macro always opens a new window; dropping onto an open window replaces its model (unsaved changes → a question).
  • Only the first of several dropped files opens; nothing opens during an analysis.

Inventor parts and assemblies and Fusion designs without STEP export (module native)

With the optional module native (Tools → Program modules…) you open an Inventor part .ipt, assembly .iam and Fusion design .f3d / .f3z directly – no CAD and no STEP export needed (Open, drag onto the window, Replace geometry). The program reads the exact ShapeManager geometry and converts it to solids; it is cached as STEP, so everything else works the same.

  • Every solid is checked (valid topology, positive volume). What cannot be converted reliably (thread helices without a stored approximation, elliptic cylinders) stops with an explanation – then use STEP.
  • Inventor assemblies .iam carry only references and positions: the .ipt (and subassembly .iam) files must lie next to the assembly in the same folder structure (copying the whole project folder is enough). Parts are placed at occurrence positions, including subassemblies; body names as in Inventor (Plate:2, several bodies Plate:2_1…). Positions are checked against the assembly and the graphics stored by Inventor. Verified on an assembly of 21 occurrences with a subassembly (no interference, volumes = Inventor STL to 0.05 %). Bolts, nuts and washers (by name, including Content Center) are not loaded but replaced by virtual bolts with a joint assessment – see Joints. Not yet supported: renamed and suppressed occurrences (clear error); hidden occurrences load as visible.
  • Fusion assemblies (.f3d with components, .f3z with nested documents): the component tree, positions and visibility are built. Bodies hidden in Fusion (light bulb off) load as hidden and excluded – switch them on in Model with the Show / Analyze columns. Names as in Fusion / STEP (Plate:1, Plate:1_1…). Verified against a Fusion STEP export (nested document, rotated occurrences, hidden bodies: positions and volumes to 1e-14). If the tree cannot be read, the program warns and loads bodies in component coordinates.
  • Materials are not transferred from native files (the Fusion add-in sends them in metadata).
  • This is unofficial reading of Autodesk formats: for important models compare with a STEP export (volume, dimensions).

Materials from CAD – a JSON file next to the STEP file

STEP does not carry the part material. The Fusion add-in and the SOLIDWORKS and Inventor tools therefore write a file with the same name and the .json extension next to the STEP (e.g. Drzak_20261015_101500.step + Drzak_20261015_101500.json). When FEA Studio opens the STEP (any way above), it:

  1. matches STEP parts to records by name (case and occurrence suffixes “:1”, “<1>”, “ (2)”, “_2”, SOLIDWORKS “-1” do not matter);
  2. assigns a material only if it is in the library: exact name (also from your library), or the same grade by the grade converter. A temper in the CAD name (T6, O, +QT…) must match;
  3. leaves other parts on the default Steel S235 and reports them.

The summary is in the Messages dock (source “CAD import”; double-click opens Materials) and the Solver log. Nothing is blocked; no window opens.

Save a material you use often in CAD in Materials with Save to my material library under the same name as in CAD (e.g. “Plain Carbon Steel”); it is then assigned automatically.

Your own JSON (another CAD, a script)

Any program can write the file: UTF-8, only the parts list is required. names = further names for matching; material_props (Re_MPa, Rm_MPa) optionally confirm the temper:

{"source": "My CAD", "document": "Bracket", "units": "mm",
 "parts": [{"name": "Plate", "material": "S235JR"},
           {"name": "Console-1", "names": ["Console"], "material": "AISI 304"}]}

The JSON is read only for a new study from STEP (a .fea project keeps its materials). Colours and units from the JSON are not used – the STEP file applies.

Autodesk Fusion

The “Odeslat do FEA Studia” add-in (recommended)

  1. Installation: the FEA Studio installer adds the add-in if Fusion is on the computer. Otherwise, in the FEA Studio folder: .venv\Scripts\python.exe installer\fea_setup.py fusion (removal: fusion --remove). Restart Fusion.
  2. In the Design workspace the SOLID, SURFACE, SHEET METAL… tabs have the FEA STUDIO panel (between INSERT and SELECT) with Odeslat do FEA Studia; also in UTILITIES → ADD-INS.
  3. In the dialog choose Co odeslat: Celý design (whole design), or Vybrané díly / podsestavy (selected parts / subassemblies – select beforehand; the selection is prefilled). Parts keep their assembly position.
  4. The add-in saves STEP + JSON to %TEMP%\FEAStudio\export and opens FEA Studio; with the REST server running, it sends the files through it (see Automation).
  • Parts are named after the occurrence (“Deska:1”); several bodies “Deska:1_1”, “Deska:1_2”.
  • Hidden bodies are not exported – make everything to be analysed visible.
  • T-Spline (Form) and mesh bodies are not written to STEP – convert them to solids.
  • The Vybrané díly / podsestavy option has not yet been tried in live Fusion.

Manual export

File → Export → type STEP Files (*.stp, *.step) → location → Export. Open the STEP in FEA Studio. Materials are not transferred this way.

The FEAStudio_Export macro (button)

Macro file: adapters\solidworks\FEAStudio_Export.bas in the FEA Studio folder. Installation (once):

  1. Tools → Macro → New → name FEAStudio.swp (not FEAStudio_Export) in the adapters\solidworks folder → Save. The VBA editor opens.
  2. In the editor File → Import File… (Ctrl+M) → FEAStudio_Export.bas.
  3. Remove the empty default module (right-click → Remove… → No).
  4. Debug → Compile VBAProject, save (Ctrl+S), close the editor.
  5. Button: Tools → Customize → Commands → category Macro → drag New Macro Button to a toolbar. Macro: FEAStudio.swp, Method: FEAStudio_Export.main, image FEAStudio_Export.bmp.

When clicked, the macro sets AP214, solid/surface geometry, face/edge properties, unsplit periodic faces and no 3D curves for the export (then restores them), saves STEP + JSON (material, configuration, occurrences) to %TEMP%\FEAStudio\export and launches FEA Studio. Check the options added in 2023 – separate STEP files (off), Export appearances (on), Output coordinate system (default) – once manually; the macro does not change them.

  • STEP from SOLIDWORKS has no occurrence names (“Deska-1”): parts are named after the part file (“Deska”, “Deska (2)”), and “Deska_Configuration” for a non-default configuration. The JSON still matches them.
  • Accented names are written correctly only from SOLIDWORKS 2024 SP02; in older versions use names without accents.
  • Detailed description (Czech): adapters\solidworks\README.md.

Autodesk Inventor

Manual export

File → Export → CAD Format → type STEP Files → Options…: Application Protocol 214 (AP242 only for parts, not assemblies), turn off Include Sketches → Save.

The FEAStudio_Export iLogic rule

Rule file: adapters\inventor\FEAStudio_Export.iLogicVb in the FEA Studio folder. Installation (once):

  1. Tools → Options → iLogic Configuration → External Rule Directories → + → the adapters\inventor folder → OK.
  2. Running: Manage → iLogic → iLogic Browser → External Rules → right-click FEAStudio_Export → Run Rule.
  3. Button (Inventor 2023+): right-click the ribbon → Customize User Commands → Ribbon → filter iLogic rules → add FEAStudio_Export (Part and Assembly separately). Inventor 2021–2022 has no button for a rule – run it from the iLogic Browser.
  4. Inventor 2025+ may ask about security on the first run (the rule starts another program) – allow it.

The rule saves STEP AP214 without sketches + JSON to %TEMP%\FEAStudio\export and launches FEA Studio.

  • Inventor library material names are generic and localised (“Steel, Mild”, “Ocel, měkká”) and are not assigned; grades such as “1.4301” or “S235JR” are.
  • Depending on the version, hidden components may go to STEP – suppress unneeded parts.
  • Inventor writes the Windows login name into the STEP header – keep this in mind when sharing files.
  • Detailed description (Czech): adapters\inventor\README.md.

Where the macro and the rule find FEA Studio

In order: the FEA_STUDIO_HOME environment variable → %APPDATA%\FEAStudio\install.json (written by the installer) → %LOCALAPPDATA%\Programs\FEA Studio → a constant in the macro. If none is found, a message gives the path of the saved STEP – drag it onto the window. Set the variable via Start → “Edit environment variables for your account” → New…: name FEA_STUDIO_HOME, value = the FEA Studio folder (e.g. D:\Programs\FEA Studio).

Unsuitable formats and tools

  • STL, OBJ, 3MF, PLY – triangle meshes without precise surfaces (STL also without units). Not opened.
  • Converting a mesh to a solid (FreeCAD “Convert to solid”, STL → STEP) gives a faceted solid with a face per triangle: slow meshing, holes and cylinders cannot be selected, and false stress peaks appear on facet edges. Last resort only – remodelling is better.
  • IGES usually carries surfaces only and is not opened. Native CAD files (.sldprt, .ipt, .f3d…), Parasolid and ACIS are not either – always export STEP.
  • SketchUp, Blender and other polygon modellers have neither precise solids nor STEP export.

Simplifying a large model

  • Suppress parts that carry no load (cables, electronics, covers, labels).
  • Turn off modelled threads (helices); remove cosmetic threads, logos and text.
  • Remove small fillets, chamfers and holes far from stressed areas – they refine the mesh needlessly.
  • Use symmetry (half or quarter model with supports in the symmetry plane, Supports).
