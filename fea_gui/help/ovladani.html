Controls and keys

Window layout, interactive help (What's this?, setup guide), mouse control in the 3D window (as in Onshape), selection of faces and parts, section view, views, undo/redo and saving. At the end: all keyboard shortcuts.

Window layout

  • Top – one header row: menus File (Open, Save, Save as, Report, Replace geometry), Edit (Undo, Redo), View (Fit, view direction, optional steps, Appearance – system / light / dark, Language), Tools and Help (F1 help, What's this? Shift+F1, How to set up a simulation, guided tours, manuals). In the middle are the phase tabs Model, Assembly, Conditions, Calculation, Results; on the right the study and file name, the phase button (Model: Replace geometry…; Assembly: Detect joints…; Calculation: Mesh convergence…; Results: Export CSV / VTU and Generate report) and Run analysis (F5 – opens Solve and runs). A phase tab opens the step used last in that phase. In a narrow window the document name disappears first, then the Replace geometry button (it stays in File).
  • Above the 3D window – the view bar: description by step (load case, joints, mesh, displayed quantity), material colour legend, what a click does; by phase: Model Color (part / material), Assembly Transparent, Conditions Shaded (with edges, without, wireframe), Mesh Show: Mesh / Parts and Color: element quality (1 = regular tetrahedron), Results Quantity and Mesh edges; then Select (Face P, Body B, Hole H, Edge E, Point V), View (isometric, front, top, right), Section (plane normal to an axis or to a selected face; position slider; flip) and Fit (F).
  • Left – tool shelf: commands of the current step in headed groups (e.g. Model: GEOMETRY Load, Replace, Check; PARTS Show, Isolate, Hide, Exclude; Loads: LOADS Force, Pressure, Moment, Bearing, Weight, Add; CASES New case, Combinations; Results: Along line, Isosurface, Section force, Animate, Export; Heat: Temperature, Flux, Convection, Radiation; Contacts: Find, Add pair; Members: Node, Member, Section, From wires; Motion: Body, Joint, Driver, Play). In a low window only icons remain; names are in tooltips.
  • Centre – 3D window.
  • Right – at the top the Study tree (parts with material, 3D printing, joints, contacts, beams, supports, mechanism, heat, load cases, dynamics and added mass, mesh, results, fatigue). A click switches to the item's step and selects it. Below the tree are the step tabs of the phase with a status dot: green = done, orange = warning or unfinished, red = error or missing input, gray = not used. A new STEP study shows only the eight required steps (Model, Materials, Joints, Supports, Loads, Mesh, Solve, Results); optional steps (3D printing, Contacts, Members, Motion, Heat, Dynamics, Fatigue) appear when the study uses them, or pin with + (also View → Optional workflow steps). Ctrl+PgDown / Ctrl+PgUp switch steps. Below the tabs: the Properties – selected item card (part: volume, mass, Show / Analyse, material with E, ν, ρ, Re, Rm; bolt: designation, preload, clamped parts, utilization; support and load: where it acts, area, value; Mesh and Solve: analysis state with the duration of each phase, solver, size, quality, equilibrium). A bolt's size, class and preload and a force's X / Y / Z components can be changed here. The divider between tree and panel can be moved.
  • Bottom – tables in tabs with row counts: Model – Parts (Show, Analyse and Material editable), Study materials, Geometry check, Coordinate systems; Joints – Bolts, Welds, Part connections, Excluded parts; Supports and Loads – loads × cases matrix, Load cases, Combinations; Heat, Contacts, Members, Motion, Dynamics; Mesh – Mesh by part, Refinement; Results – Load case results, Highest stresses, Safety by part, Reactions, Joints – utilization. In tables you can change: parts Show, Analyse, Material; bolt size, class and preload mode; load components Fx / Fy / Fz (double-click) and the case matrix (ticking copies a load into a case, unticking in its own case deletes it); + Row adds a load on the selected faces or a bolt in the selected hole. Actions on the right of the tab row (Show all, Isolate, Filter, Assign material…, Duplicate, Delete, Show in model, Copy to Excel). The Messages dock (errors, warnings, information; double-click switches to the step), the Solver log (everything the program reports, including CalculiX output) and Joints – utilization are here too.
  • Status bar – left: probe value, edge description or selected parts; right: “Faces selected: n A = … mm²” and the model summary: readiness check, result equilibrium (✓ in green when the imbalance is below the limit), element count, time of the last solve and units (mm · N · MPa).

Selection

What a click selects depends on the step:

  • Model, Materials, 3D printing, Solve, Fatigue – whole parts. Ctrl+click adds / removes a part.
  • Joints, Contacts, Beams, Supports, Motion, Heat, Loads, Dynamics, Mesh – faces. A click adds a face, a second click removes it (no Ctrl needed); a click on empty space clears the selection. The face under the cursor is light blue; selected faces are orange. The selection carries over between Supports, Loads and Mesh.
  • Results – a click shows the value of the displayed quantity (probe) and a marker in 3D.

3D mouse (3Dconnexion)

SpaceMouse, SpaceNavigator and other 3Dconnexion devices are read directly from Windows (the 3DxWare driver may run at the same time). Push right = model right, pull = zoom in, twist and tilt = rotation about the model point in the window centre. Fit shows the whole model; on SpaceMouse Pro / Enterprise the view buttons and Roll also work. The Menu button is handled by the driver.

Right-click in the 3D window → 3D mouse (3Dconnexion) dialog: Control the 3D view with the 3D mouse, Speed (0.25× to 4×), Rotation, Pan and zoom, Dominant motion only (dominant axis), and inversion of single axes. The bars show the cap deflection live – useful to check the device is communicating.

Undo / redo

Ctrl+Z reverts the last study change (material, support, load, mesh, print settings, joints, fatigue…), Ctrl+Y redoes it. Up to 200 steps are kept; the history clears when another file opens. View, face selection and section are not recorded.

Note: reverting an input change discards the results (and the mesh, if it concerns geometry, selections, joints or printing). Changing fatigue settings does not discard static results.

Files

  • Open… Ctrl+O – STEP (.step, .stp) = new study, or a .fea project. Also python -m fea_gui file.fea.
  • Save Ctrl+S – the .fea project holds the STEP model, inputs and results (portable to another computer). A new study asks for a name.
  • Save as… Ctrl+Shift+S.
  • Unsaved changes show as an asterisk in the title; closing or opening another file asks first.

Recent files and autosave

File → Recent files lists the last opened or saved projects and models (only files that still exist). While a project has unsaved changes, FEA Studio saves a copy every 5 minutes to the user data folder (FEAStudio/autosave; results larger than 200 MB are left out – the study only). Saving or a normal exit removes the copy. If the program ended abnormally, the next start offers to restore it; the restored project keeps its original file name, save it to keep the changes.

Python console

Show → Python console opens a dock where you can run Python code over the open model: study, mesh, results, window, fea_core, np (Ctrl+Enter runs). The code runs inside the program with full access to your files – run only code you trust. The console is not available to MCP / LLM agents or the REST API.

In the examples

  • Example 1 – printed bracket: in Supports turn on the Hole filter (H) and click a screw hole – the whole Ø5 hole is selected. Section Y at the middle (y = 20 mm) passes through both hole axes, the Ø8 eye and the rib; in Results the same section is coloured by the stress inside the part.
  • Example 2 – assembly: the Edge filter (E) and a click on the arm eye edge shows a circle R 5 mm on the eye axis; Use circle center enters it as the remote force point. Section Y through the bolt axis shows the clamped stack with washers and nut; in Results, section Y across the post shows the triangular sections of both fillet welds and the stress in them.

Troubleshooting

  • Arrows and letter shortcuts do not respond – the focus is in a form field. Click into the 3D window.
  • “For a section along a face plane, first select a face (e.g. in the Supports step), then choose “face”.” – in Model and Materials parts are selected, not faces. Go to Supports, select a face, then choose the section “face”.
  • “Hole filter: click the cylindrical face of a hole or pin.” – you clicked a planar face or a non-cylindrical fillet (cone, torus). Click the cylindrical wall.
  • The “Solver log” or “Messages” panel disappeared (closed with the cross) – right-click the toolbar and show it again.
  • “Meshing, analysis or report generation is in progress – wait for it to finish or cancel the analysis (Solve / Mesh step).” – a file cannot be opened during an analysis. Wait, or press Cancel.
  • Results disappeared after Ctrl+Z (“Study changed – results discarded, recomputation needed.”) – results belong to the original inputs. Run the analysis again; Ctrl+Y redoes the change but does not restore results.
