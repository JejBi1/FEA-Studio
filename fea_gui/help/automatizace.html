Automation

Everything the GUI does is also available without it: the command line, Python scripts, an MCP server for AI assistants (Claude, Cursor), and a REST API for CAD adapters and other programs. The commands on this page can be copied.

Preparation

Run commands from the installation folder (e.g. C:\FEA Studio) with its Python. In PowerShell:

cd "C:\FEA Studio"
$env:PYTHONIOENCODING = "utf-8"
.venv\Scripts\python.exe -m fea_core --help

In cmd use set PYTHONIOENCODING=utf-8 instead. Without it Czech characters may be garbled.

Tip: a .fea project is a zip with study.json (input), model.step (geometry) and possibly results. For commands that need study.json, rename the project to .zip and extract it; study.json refers to model.step in the same folder.

Verification problems compare results with analytical solutions and print an agreement table – useful after installation or an update.

Export and background solve

python -m fea_core export project.fea --format vtu|csv|all [--out FOLDER] [--dialect standard|excel] [--elements]
python -m fea_core solve-project project.fea [-o solved.fea]

export writes the results of a solved project to ParaView (.vtu per load case + .pvd) and / or CSV (the same files as the GUI export). solve-project solves a project and saves it with the results as another .fea (default <name>_results.fea) – the job queue of the GUI uses it.

Python script

Templates: examples\create.py and verification\. Faces are selected geometrically (find_faces: part, plane x/y/z, cylinder radius, normal, custom condition), not by index, so the script survives model changes in CAD.

from fea_core import materials as matlib
from fea_core.geometry import read_step
from fea_core.selectors import find_faces
from fea_core.study import Study, Fixed, Force, LoadCase, MeshSettings
from fea_core.solve import run_study
from fea_core.project import save_project

parts = read_step("konzola.step")
st = Study("Konzola", "konzola.step")
st.add_material(matlib.by_name("Ocel S235"), default=True)
st.add_selection("Vetknutí", find_faces(parts, x=0))
st.add_selection("Konec", find_faces(parts, x=200))
st.constraints.append(Fixed("Vetknutí"))
st.load_cases.append(LoadCase("Síla", [Force("Konec", [0, 0, -100])]))
st.mesh = MeshSettings(size=3.0)

res = run_study(st, "konzola_run", on_log=print, parts=parts)
s = res.steps[0]
print(f"max. displacement {s.umag.max():.3f} mm, max. von Mises {s.mises.max():.1f} MPa")
save_project("konzola.fea", st, "konzola.step", res)     # open in the GUI

Run: .venv\Scripts\python.exe muj_skript.py. Units mm, N, MPa, t, s.

MCP server (AI assistants)

The MCP server exposes the whole workflow – geometry, face selections, materials, supports, loads, heat, mesh, analysis, results and PNG images, fatigue, joints, 3D printing, contacts, dynamics, mechanisms, calculators, Word report – to language models via the Model Context Protocol. An assistant can then, for example, “load bracket.step, fix the face x = 0, apply a 200 N downward bearing load to the eye, solve and show von Mises; are the maxima singularities?”.

# stdio – this is how the clients below launch it
.venv\Scripts\python.exe -m fea_core.mcp
# HTTP – one server with one shared study, URL http://127.0.0.1:8766/mcp
.venv\Scripts\python.exe -m fea_core.mcp --transport streamable-http

Options: --workdir FOLDER (default %LOCALAPPDATA%\FEAStudio\mcp, or FEA_MCP_WORKDIR), --host, --port, --token. HTTP default port 8766; REST uses 8765 – both can run together.

Warning: in HTTP mode one session (study, mesh, results) is shared by all clients – a second assistant sees and can overwrite the first one's work. For parallel independent work use another --port and --workdir, or stdio (each client has its own process). The tools read and write any path and run analyses, so without a token the server listens on 127.0.0.1 only; any other address (--host 0.0.0.0) requires --token (or FEA_MCP_TOKEN), and clients send Authorization: Bearer <token>.

Registration in all AI clients with one click

Double-click Register MCP.bat in the program folder to write the “fea-studio” server into all detected clients: Claude Desktop, Claude Code, Cursor, Windsurf, Antigravity, Gemini CLI, LM Studio, VS Code (Copilot) and Codex CLI. Originals are backed up (….fea-zaloha) and other settings kept. Then restart the clients. The installer does this too (disable with --no-mcp).

.venv\Scripts\python.exe -m fea_core.mcp.setup --dry-run    # only show what will change
.venv\Scripts\python.exe -m fea_core.mcp.setup --remove     # remove from all clients

Tip: trailing commas (VS Code mcp.json) are fine. A file that cannot be read (e.g. mcp.json with comments) is not overwritten and is listed – add the entry by hand per the examples below.

Cursor

File .cursor\mcp.json in the project, or %USERPROFILE%\.cursor\mcp.json – same content as Claude Desktop (without cwd). Antigravity: Manage MCP Servers → View raw config, same content.

What MCP offers

  • Tools (186): study (fea_study_new/open/save/status); geometry and face selections (fea_geometry_find_faces returns ids Díl#i); materials; supports (fixed, displacement, cylindrical – also several holes in one selection, remote); loads (force, pressure, gravity, remote force, bearing load, temperature); thermal cases and conditions; mesh (fea_mesh_generate); check (fea_check_readiness, incl. rigid-body motion); analysis (fea_solve_run); results (fea_results_summary, _probe, _hotspots with singularity classification, _render_image); model image; fatigue; joints; 3D printing (fea_print_get, fea_print_set, fea_print_creep, fea_print_props, fea_print_calibrate – ISO 527 calibration, fea_print_render_shell – shell fraction image without analysis, fea_print_results, variants, sweep fea_print_sweep, advice fea_print_advice, build directions fea_print_rank_build_direction, presets fea_print_presets); report (fea_report_word); beams, 2D sections, shells, natural frequencies and buckling.
  • Contacts: fea_contact_detect, fea_contact_set/list/remove, fea_contact_check, fea_contact_settings (formulation, interface meshing, NLGEOM, bolted joint interface as contact), fea_analysis_set_sequence (branches or step sequence, prescribed motion, cycles), fea_contact_results, fea_contact_render, fea_results_history (force–travel curve).
  • Dynamics: fea_dyn_settings, fea_dyn_damping_set, fea_dyn_harmonic_set, fea_dyn_transient_set, fea_dyn_random_set, fea_dyn_shock_set, fea_dyn_prestress_set, probes fea_dyn_probe_add/list/remove, added mass fea_dyn_mass_add/list/remove, results fea_dyn_results, fea_dyn_frf_get, fea_dyn_render, fea_dyn_plot, test profiles fea_dyn_profile_presets.
  • Mechanisms: bodies fea_motion_body_add/list/remove, joints fea_motion_joint_add/list/remove, fea_motion_joints_from_cad, fea_motion_force_add, fea_motion_driver_add, fea_motion_load_add, fea_motion_contact_add (Chrono), fea_motion_settings, fea_motion_check_dof, fea_motion_run, fea_motion_results, fea_motion_render, transfer to FEA fea_motion_export_loads.
  • Calculators: fea_calc_snapfit, fea_calc_pressfit, fea_calc_hertz, fea_calc_friction, fea_calc_friction_library, fea_calc_mechanism, fea_calc_damping, fea_calc_drop.
  • Asynchronous jobs: fea_job_start (kind solve = whole study like fea_solve_run, or motion) returns a job_id at once; fea_job_status (fraction 0–1, phase, time, last log lines), fea_job_cancel, fea_job_result. One job at a time; default time limits: linear 30 min, dynamics 2 h, contact 4 h, mechanism 1 h.
  • Prompts: fea_setup_static_analysis, fea_setup_thermal_analysis, fea_mesh_convergence_check, fea_interpret_stress_results, fea_setup_contact, fea_setup_vibration_test, fea_setup_mechanism – prepared procedures.
  • An assistant saves its study with fea_study_save as a regular .fea project (with results) – open and check it in the GUI.

Warning: an assistant may specify supports or loads differently from what you intended. Always check the input (model image with arrows, fea_study_status, or the project in the GUI), as you would any manual input.

REST API

An HTTP interface with the same tools as MCP (same names, parameters and error messages), for CAD adapters, scripts in other languages and internal applications.

# this computer only, port 8765
.venv\Scripts\python.exe -m fea_core.rest
# different port and a token
.venv\Scripts\python.exe -m fea_core.rest --port 8775 --token TAJNE_HESLO
# access from the network (only with a token)
.venv\Scripts\python.exe -m fea_core.rest --host 0.0.0.0 --token TAJNE_HESLO
  • The default address 127.0.0.1 = this computer only. Any other address without a token is rejected.
  • With a token (--token or FEA_REST_TOKEN) each request needs Authorization: Bearer <token>.
  • Documentation of all endpoints and tools in the browser: http://127.0.0.1:8765/docs.
  • One server = one open study. During an analysis other requests return 409 (busy); /api/status and fea_job_status, fea_job_cancel, fea_job_result always respond – so start long analyses asynchronously (fea_job_start).
EndpointWhat it doesNote
GET /api/statusVersion, open study, busy, results, last import.
GET /api/toolsTools with the JSON schema of their parameters.
POST /api/tools/{name}Calls a tool; body = JSON arguments.?images=url|base64|both for images
GET /api/studyCurrent input (study JSON).
POST /api/importImport of STEP + CAD metadata (multipart file, metadata).Creates a study, matches parts by name, assigns library materials.
GET /api/files/{path}Download from the working folder (PNG, .docx, .fea).
POST /api/open-guiOpens a file (default the last import) in the GUI.The GUI runs separately.

PowerShell example (import with curl.exe, not the alias curl; tools with Invoke-RestMethod):

Invoke-RestMethod http://127.0.0.1:8765/api/status
curl.exe -F "file=@drzak.step" http://127.0.0.1:8765/api/import
Invoke-RestMethod -Method Post -ContentType "application/json" -Body '{"x": 0}' `
    -Uri http://127.0.0.1:8765/api/tools/fea_geometry_find_faces

Metadata format and a Python example: fea_core\rest\README.md.

CAD adapters

An adapter exports the model to STEP with body names, adds metadata (material and properties, colour, attributes) and sends them to the REST API. Without a running server it saves STEP + JSON to a folder and starts the GUI (variable FEA_STUDIO_HOME = installation folder). A material is assigned only if it matches the library (e.g. “S235”, “AISI 304”); generic names (“Steel”) are reported and not assigned.

CADInstallation and useVerification status
Autodesk FusionCopy the folder adapters\fusion\FEAStudio to %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\ (or Tools → Add-Ins → Scripts and Add-Ins → Add-Ins → “+”). Run the add-in; the Odeslat do FEA Studia (Send to FEA Studio) button is in the FEA STUDIO panel between INSERT and SELECT (SOLID, SURFACE, MESH, SHEET METAL… tabs) and in UTILITIES → ADD-INS. Settings in settings.json (template settings.example.json) or the variables FEA_REST_URL, FEA_REST_TOKEN, FEA_STUDIO_HOME.Export and metadata verified on a real assembly; the toolbar button verified in live Fusion.

Metadata from Fusion also contain the joints (type, axis, limits); the Motion step proposes mechanism joints from them with From Fusion metadata… (not yet verified in live Fusion).

Procedure: start the REST server (python -m fea_core.rest), then the adapter in CAD. Parts keep the CAD names (for Fusion the occurrence name, e.g. “Deska:1”); metadata are matched by them.

Installation and modules

The program is installed by modules: a small base (the FEA core) and optional parts that can be added or removed at any time. Everything stays in the program folder (.venv, tools); no administrator rights are needed. Details: installer\README.md.

  1. Extract FEAStudio-<version>.zip (Linux .tar.gz) to a permanent folder – not a synchronised one (OneDrive, Dropbox…).
  2. Run Install FEA Studio.bat (Linux ./install.sh) and choose: minimal (core), standard (+ GUI, plots, Numba, PARDISO, beams, report, mechanisms), full (+ MCP/REST, NGSolve, hypre), or a custom selection. Without prompts: Install FEA Studio.bat --profile standard --quiet.
  3. The installer downloads uv, Python 3.11, the locked packages and CalculiX 2.23, prunes unneeded files, creates shortcuts and the .fea association, and runs a verification analysis. Running it again is safe.

.venv\Scripts\python.exe -m fea_core.modules install chrono
.venv\Scripts\python.exe -m fea_core.modules remove report mcp

The same in the GUI: Tools → Program modules…. Without a module the program does not crash: the function that needs it reports “Module … is missing. Install it: python -m fea_core.modules install …” (e.g. without chrono the Chrono solver in Motion is greyed out). Other installer commands: python installer\fea_setup.py install | remove | list | slim | doctor | shortcuts | mpi | uninstall [--all]; uninstalling from the Start menu removes shortcuts and the extension; uninstall --all also removes .venv and tools.

Common problems

Message / symptomCause and solution
ModuleNotFoundError: No module named 'fea_core'Python from outside the installation, or another working folder. Use .venv\Scripts\python.exe from the installation; in the MCP configuration set cwd and PYTHONPATH to the installation folder.
Garbled Czech characters in outputSet PYTHONIOENCODING=utf-8 (in the MCP env).
REST or MCP (HTTP) does not start – port in useAnother program or instance uses the port. REST default 8765 (used by CAD adapters), MCP HTTP 8766. Start with another --port (and set the same address in the adapter via FEA_REST_URL).
REST responds 401 / 403401: token missing or wrong (header Authorization: Bearer …). 403: a request from an address other than 127.0.0.1 / localhost without a token, or from a web page (protection against browser abuse).
