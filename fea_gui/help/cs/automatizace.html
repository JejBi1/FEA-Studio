Automatizace

Vše, co dělá GUI, jde i bez něj: příkazová řádka, skripty v Pythonu, server MCP pro AI asistenty (Claude, Cursor) a rozhraní REST pro adaptéry CADu a další programy. Příkazy na této stránce lze kopírovat.

Příprava

Příkazy spouštějte ze složky instalace (např. C:\FEA Studio) jejím Pythonem. V PowerShellu:

cd "C:\FEA Studio"
$env:PYTHONIOENCODING = "utf-8"
.venv\Scripts\python.exe -m fea_core --help

V příkazovém řádku cmd místo druhého řádku použijte set PYTHONIOENCODING=utf-8. Bez toho mohou být české znaky ve výstupu poškozené.

Tip: projekt .fea je zip s study.json (vstup), model.step (geometrie) a případně výsledky. Pro příkazy, které potřebují study.json, přejmenujte projekt na .zip a rozbalte jej; study.json odkazuje na model.step ve stejné složce.

Skript v Pythonu

Šablony: examples\create.py a verification\. Plochy se vybírají geometricky (find_faces: díl, rovina x/y/z, poloměr válce, normála, vlastní podmínka), ne podle indexu, takže skript přežije změny modelu v CADu.

from fea_core import materials as matlib
from fea_core.geometry import read_step
from fea_core.selectors import find_faces
from fea_core.study import Study, Fixed, Force, LoadCase, MeshSettings
from fea_core.solve import run_study
from fea_core.project import save_project

parts = read_step("konzola.step")
st = Study("Konzola", "konzola.step")
st.add_material(matlib.by_name("Ocel S235"), default=True)
st.add_selection("Vetknutí", find_faces(parts, x=0))
st.add_selection("Konec", find_faces(parts, x=200))
st.constraints.append(Fixed("Vetknutí"))
st.load_cases.append(LoadCase("Síla", [Force("Konec", [0, 0, -100])]))
st.mesh = MeshSettings(size=3.0)

res = run_study(st, "konzola_run", on_log=print, parts=parts)
s = res.steps[0]
print(f"max. posuv {s.umag.max():.3f} mm, max. von Mises {s.mises.max():.1f} MPa")
save_project("konzola.fea", st, "konzola.step", res)     # otevřít v GUI

Spuštění: .venv\Scripts\python.exe muj_skript.py. Jednotky mm, N, MPa, t, s.

Server MCP (AI asistenti)

Server MCP zpřístupňuje celý postup – geometrii, výběry ploch, materiály, vazby, zatížení, teplo, síť, výpočet, výsledky a obrázky PNG, únavu, spoje, 3D tisk, kontakty, dynamiku, mechanismy, kalkulačky a protokol Word – jazykovým modelům přes Model Context Protocol. Asistent pak může například „načíst bracket.step, vetknout plochu x = 0, na oko přidat ložnou sílu 200 N dolů, spočítat a ukázat von Mises; jsou maxima singularity?“.

# stdio – takto jej spouštějí klienti níže
.venv\Scripts\python.exe -m fea_core.mcp
# HTTP – jeden server se sdílenou studií, URL http://127.0.0.1:8766/mcp
.venv\Scripts\python.exe -m fea_core.mcp --transport streamable-http

Volby: --workdir SLOŽKA (výchozí %LOCALAPPDATA%\FEAStudio\mcp, nebo FEA_MCP_WORKDIR), --host, --port, --token. Výchozí port HTTP je 8766, REST používá 8765 – mohou běžet obě současně.

Pozor: v režimu HTTP sdílí všichni klienti jednu relaci (studii, síť, výsledky) – druhý asistent vidí práci prvního a může ji přepsat. Pro paralelní nezávislou práci použijte jiný --port a --workdir, nebo stdio (každý klient má vlastní proces). Nástroje čtou a zapisují soubory na libovolné cestě a spouštějí výpočty, takže bez tokenu server poslouchá jen na 127.0.0.1; jiná adresa (--host 0.0.0.0) vyžaduje --token (nebo FEA_MCP_TOKEN) a klienti posílají Authorization: Bearer <token>.

Registrace do všech AI klientů jedním kliknutím

Dvojklikem na Register MCP.bat ve složce programu zapíšete server „fea-studio“ do všech nalezených klientů: Claude Desktop, Claude Code, Cursor, Windsurf, Antigravity, Gemini CLI, LM Studio, VS Code (Copilot) a Codex CLI. Původní soubory se zálohují (….fea-zaloha), ostatní nastavení se zachovají. Pak klienty restartujte. Instalátor to dělá také (vypnutí --no-mcp).

.venv\Scripts\python.exe -m fea_core.mcp.setup --dry-run    # jen ukáže, co se změní
.venv\Scripts\python.exe -m fea_core.mcp.setup --remove     # odebere ze všech klientů

Tip: koncové čárky v souboru (VS Code mcp.json) nevadí. Soubor, který nejde přečíst (např. mcp.json s komentáři), program nepřepíše a uvede jej v seznamu – položku doplňte ručně podle příkladů níže.

Claude Desktop

Soubor %APPDATA%\Claude\claude_desktop_config.json (Nastavení → Vývojář → Upravit konfiguraci):

{
  "mcpServers": {
    "fea-studio": {
      "command": "C:\\FEA Studio\\.venv\\Scripts\\python.exe",
      "args": ["-m", "fea_core.mcp"],
      "cwd": "C:\\FEA Studio",
      "env": {"PYTHONPATH": "C:\\FEA Studio", "PYTHONIOENCODING": "utf-8"}
    }
  }
}

Po uložení restartujte Claude Desktop.

Claude Code

claude mcp add --scope user fea-studio -e PYTHONPATH="C:\FEA Studio" -e PYTHONIOENCODING=utf-8 -- "C:\FEA Studio\.venv\Scripts\python.exe" -m fea_core.mcp

Název serveru musí být před -e; bez --scope user platí položka jen ve složce, kde se příkaz spustil.

Cursor

Soubor .cursor\mcp.json v projektu, nebo %USERPROFILE%\.cursor\mcp.json – stejný obsah jako pro Claude Desktop (bez cwd). Antigravity: Manage MCP Servers → View raw config, stejný obsah.

Co MCP nabízí

  • Nástroje (186): studie (fea_study_new/open/save/status); geometrie a výběry ploch (fea_geometry_find_faces vrací id Díl#i); materiály; vazby (vetknutí, posuv, válcová – i více děr v jednom výběru, vzdálená); zatížení (síla, tlak, tíha, vzdálená síla, ložisková síla, teplota); tepelné stavy a podmínky; síť (fea_mesh_generate); kontrola (fea_check_readiness, včetně tuhých pohybů); výpočet (fea_solve_run); výsledky (fea_results_summary, _probe, _hotspots s klasifikací singularit, _render_image); obrázek modelu; únava; spoje; 3D tisk (fea_print_get, fea_print_set, fea_print_creep, fea_print_props, fea_print_calibrate – kalibrace z tahových zkoušek ISO 527, fea_print_render_shell – obrázek řezu s podílem skořepiny bez výpočtu, fea_print_results, varianty, rozmítání fea_print_sweep, rada fea_print_advice, směry stavby fea_print_rank_build_direction, předvolby fea_print_presets); protokol (fea_report_word); pruty, 2D řezy, skořepiny, vlastní frekvence a vzpěr.
  • Kontakty: fea_contact_detect, fea_contact_set/list/remove, fea_contact_check, fea_contact_settings (formulace, síťování spáry, NLGEOM, šroubová spára jako kontakt), fea_analysis_set_sequence (větve nebo posloupnost kroků, předepsaný pohyb, cykly), fea_contact_results, fea_contact_render, fea_results_history (křivka síla–dráha).
  • Dynamika: fea_dyn_settings, fea_dyn_damping_set, fea_dyn_harmonic_set, fea_dyn_transient_set, fea_dyn_random_set, fea_dyn_shock_set, fea_dyn_prestress_set, sondy fea_dyn_probe_add/list/remove, přidaná hmota fea_dyn_mass_add/list/remove, výsledky fea_dyn_results, fea_dyn_frf_get, fea_dyn_render, fea_dyn_plot, zkušební profily fea_dyn_profile_presets.
  • Mechanismy: tělesa fea_motion_body_add/list/remove, klouby fea_motion_joint_add/list/remove, fea_motion_joints_from_cad, fea_motion_force_add, fea_motion_driver_add, fea_motion_load_add, fea_motion_contact_add (Chrono), fea_motion_settings, fea_motion_check_dof, fea_motion_run, fea_motion_results, fea_motion_render, převod do MKP fea_motion_export_loads.
  • Kalkulačky: fea_calc_snapfit, fea_calc_pressfit, fea_calc_hertz, fea_calc_friction, fea_calc_friction_library, fea_calc_mechanism, fea_calc_damping, fea_calc_drop.
  • Úlohy na pozadí: fea_job_start (druh solve = celá studie jako fea_solve_run, nebo motion) vrátí hned job_id; fea_job_status (podíl 0–1, fáze, čas, poslední řádky logu), fea_job_cancel, fea_job_result. Současně běží nejvýše jedna úloha; výchozí časové limity: lineární 30 min, dynamika 2 h, kontakt 4 h, mechanismus 1 h.
  • Prompty: fea_setup_static_analysis, fea_setup_thermal_analysis, fea_mesh_convergence_check, fea_interpret_stress_results, fea_setup_contact, fea_setup_vibration_test, fea_setup_mechanism – připravené postupy pro asistenta.
  • Asistent uloží svou studii nástrojem fea_study_save jako běžný projekt .fea (i s výsledky) – otevřete a zkontrolujte ji v GUI.

Pozor: asistent může zadat vazby nebo zatížení jinak, než jste zamýšleli. Vstup vždy kontrolujte (obrázek modelu se šipkami, fea_study_status, nebo projekt v GUI) stejně jako každý ruční vstup.

REST API

HTTP rozhraní se stejnými nástroji jako MCP (stejné názvy, parametry a chybová hlášení), určené pro adaptéry CADu, skripty v jiných jazycích a interní aplikace.

# jen tento počítač, port 8765
.venv\Scripts\python.exe -m fea_core.rest
# jiný port a token
.venv\Scripts\python.exe -m fea_core.rest --port 8775 --token TAJNE_HESLO
# přístup ze sítě (jen s tokenem)
.venv\Scripts\python.exe -m fea_core.rest --host 0.0.0.0 --token TAJNE_HESLO
  • Výchozí adresa 127.0.0.1 = jen tento počítač. Jiná adresa bez tokenu se odmítne.
  • S tokenem (--token nebo FEA_REST_TOKEN) musí každý požadavek nést Authorization: Bearer <token>.
  • Dokumentace všech koncových bodů a nástrojů v prohlížeči: http://127.0.0.1:8765/docs.
  • Jeden server = jedna otevřená studie. Během výpočtu ostatní požadavky vracejí 409 (zaneprázdněno); /api/status a fea_job_status, fea_job_cancel, fea_job_result odpovídají vždy – dlouhý výpočet proto spouštějte asynchronně (fea_job_start).

Příklad v PowerShellu (import přes curl.exe, ne přes alias curl; nástroje přes Invoke-RestMethod):

Invoke-RestMethod http://127.0.0.1:8765/api/status
curl.exe -F "file=@drzak.step" http://127.0.0.1:8765/api/import
Invoke-RestMethod -Method Post -ContentType "application/json" -Body '{"x": 0}' `
    -Uri http://127.0.0.1:8765/api/tools/fea_geometry_find_faces

Formát metadat a příklad v Pythonu: fea_core\rest\README.md.

Adaptéry CADu

Adaptér exportuje model do STEP s názvy těles, přidá metadata (materiál a jeho vlastnosti, barvu, atributy) a pošle je do REST API. Není-li server spuštěn, uloží STEP + JSON do složky a spustí GUI (proměnná FEA_STUDIO_HOME = složka instalace). Materiál se ve FEA Studiu přiřadí jen tehdy, když odpovídá knihovně (např. „S235“, „AISI 304“); obecné názvy („Steel“) se nepřiřadí a ohlásí se.

CADInstalace a použitíStav ověření
Autodesk FusionZkopírujte složku adapters\fusion\FEAStudio do %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\ (nebo Nástroje → Doplňky → Skripty a doplňky → Doplňky → „+“). Doplněk spusťte; tlačítko Odeslat do FEA Studia je v panelu FEA STUDIO mezi VLOŽIT a VYBRAT (karty SOLID, SURFACE, MESH, SHEET METAL…) a také v UTILITIES → ADD-INS. Nastavení v settings.json (šablona settings.example.json) nebo v proměnných FEA_REST_URL, FEA_REST_TOKEN, FEA_STUDIO_HOME.Export a metadata ověřeny na skutečné sestavě; tlačítko na panelu ověřeno v ostrém Fusionu.

Metadata z Fusionu obsahují i klouby (typ, osa, meze); krok Pohyb z nich navrhne klouby mechanismu tlačítkem Z metadat Fusionu… (v ostrém Fusionu zatím neověřeno).

Postup: spusťte REST server (python -m fea_core.rest), pak adaptér v CADu. Díly ve FEA Studiu mají názvy z CADu (u Fusionu název výskytu, např. „Deska:1“); metadata se podle nich párují.

Instalace a moduly

Program se instaluje po modulech: malý základ (jádro FEA) a volitelné části, které lze kdykoli přidat nebo odebrat. Vše zůstává ve složce programu (.venv, tools); práva správce nejsou potřeba. Podrobnosti: installer\README.md.

  1. Rozbalte FEAStudio-<verze>.zip (Linux .tar.gz) do trvalé složky – ne do synchronizované (OneDrive, Dropbox…).
  2. Spusťte Install FEA Studio.bat (Linux ./install.sh) a zvolte: minimální (jen jádro), standardní (+ GUI, grafy, Numba, PARDISO, pruty, protokol, mechanismy), úplná (+ MCP/REST, NGSolve, hypre), nebo vlastní výběr. Bez dotazů: Install FEA Studio.bat --profile standard --quiet.
  3. Instalátor stáhne uv, Python 3.11, zamčené balíčky a CalculiX 2.23, odstraní nepotřebné soubory, vytvoří zástupce a přidružení .fea a spustí ověřovací výpočet. Opakované spuštění je bezpečné.
