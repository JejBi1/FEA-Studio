FEA Studio – nápověda

Pevnostní analýza dílů a sestav: lineární statika, kontakty a nelineární analýza, vlastní frekvence, vzpěr, dynamika (kmitání, náhodné kmitání, ráz), optimalizace topologie (BESO), kombinace zatížení (EN 1990), mechanismy, šroubové a svarové spoje, díly z 3D tisku, prutové soustavy (Timošenko), vedení tepla a teplotní napětí, únava (S-N i ε-N). Řešič CalculiX, síťovač Gmsh, Exudyn pro mechanismy. Několik funkcí je dostupných jen přes MCP server nebo Python API, ne v tomto okně – viz níže.

Začínáme

  1. Ukázky s průvodcem (nejrychlejší): Ukázka 1 – tištěný držák, Ukázka 2 – ocelová + tištěná sestava, Ukázka 3 – přírubový spoj (VDI 2230), Ukázka 4 – svařované rameno, Ukázka 5 – chladič elektroniky. Průvodce ukázku otevře a vysvětlí každý krok – Ukázky a průvodce.
  2. Testování: sedm úloh se známým výsledkem – Testování programu.
  3. Vlastní model: Ctrl+O, soubor STEP z CAD (Fusion, Onshape, SolidWorks…), pak záložky fází zleva doprava. Volitelné analýzy (3D tisk, Kontakty, Pruty, Pohyb, Teplo, Dynamika, Únava) se přidají tlačítkem + za záložkami kroků (nebo Zobrazit → Volitelné kroky postupu).

Tip: F1 = nápověda k prvku pod kurzorem nebo k aktuálnímu kroku; Shift+F1 = interaktivní režim „Co je to?“. Jazyk (🇨🇿 Čeština / 🇬🇧 English) a vzhled: nabídka Zobrazit.

Postup (fáze a kroky)

Pět fází seskupuje kroky: Model (Model, Materiály, 3D tisk), Sestava (Spoje, Kontakty, Pruty), Podmínky (Podpory, Pohyb, Teplo, Zatížení, Dynamika), Výpočet (Síť, Řešení), Výsledky (Výsledky, Únava). Kroky fáze jsou záložky nad pravým panelem. Nová studie ukazuje osm základních kroků; ostatní se aktivují podle obsahu studie nebo tlačítkem +. Panely mají sbalitelné sekce. Tečka kroku: zelená = hotovo, oranžová = varování nebo probíhá, červená = chybí povinný vstup, šedá = nepoužito. Strom studie (vpravo nahoře) ukazuje totéž; klik na položku otevře krok.

Viz také: Protokol Word (Ctrl+P), Ovládání a klávesy, Automatizace (příkazová řádka, MCP, REST, adaptéry CAD).

Co program počítá a co ne

  • Lineárně: pružnost (malé deformace, izotropní i ortotropní / tištěný materiál), superpozice stavů, únava, vedení tepla a teplotní napětí, šrouby jako předepnuté nosníky, svary jako tělesa, prutové soustavy (Timošenko), 2D řez, skořepiny, vlastní frekvence, lineární i nelineární vzpěr (imperfekce, GNIA / GMNIA), kombinace EN 1990 (STR/GEO, EQU, MSP).
  • Nelineárně a pokročile (bez superpozice; vždy CalculiX): kontakt (oddělení, tření, přesah, jen tlak; dokonalé vedení tepla přes uzavřené páry), rozhraní šroubových spojů jako kontakt (otevření, skluz), velké deformace, optimalizace topologie (BESO s filtrem citlivosti a penalizací), posloupnost kroků s předepsaným pohybem (křivka síla–dráha), plasticita kovů (bilineární, vícelineární tabulka, Ramberg-Osgood, Hollomon; izotropní / kinematické zpevnění) s ekvivalentním plastickým přetvořením PEEQ, zbytkovým napětím po odlehčení a posouzením podle EN 1993-1-5 přílohy C / ASME VIII-2.
  • Dynamika: harmonická a přechodová odezva, náhodné kmitání, ráz, únava sinusovým přejezdem a spektrální únava modální superpozicí (lineární model, bez kontaktu), přidaná hmota.
  • Mechanismy: kinematika a dynamika tuhých těles (Exudyn) – reakce kloubů, pohony, tření, animace, přenos okamžiku nebo celého průběhu do MKP; volitelně poddajná tělesa (Craig–Bampton) a kontakt těles (modul Chrono).
  • Submodel: jemnější místní model kritické oblasti (kvádr nebo koule) řízený globálním posuvem na řezu, s kontrolou řezu – krok Výsledky, tlačítko Submodel… (také MCP fea_submodel_run).
  • Kalkulačky bez MKP (nabídka Nástroje): nosníky, tření, Hertzův kontakt, lisovaný spoj, západka, mechanismy, tlumení z měření, pád – viz Ovládání.
  • Jen přes MCP server / Python API (ne v tomto okně): naměřené parametry ε-N (FatigueSettings.en_params); implicitní dynamika posloupnosti kroků s kontaktem (LoadStep.dynamic, jen Python API / soubor studie). Viz Automatizace.
  • Ne: modální dynamika (superpozicí) s kontaktem, rychlostně závislé tření v kontaktu MKP (jen Coulomb), gyroskopické jevy a změkčení vřetenem v Campbellově diagramu.

Poznámka: napětí nad mezí kluzu v lineární analýze není skutečné – znamená jen začátek tečení (skutečná plastická deformace vyžaduje plastický materiál – Materiály → Plasticita). Špičky v ostrých vnitřních rozích, na okrajích pevných podpor a pod bodovými silami jsou singularity (rostou se zjemněním; tabulka maxim je označuje). Tuhost kontaktu K a tření μ jsou odhady, tlumení má citlivost ±50 %: výsledky ověřte citlivostí.

Jednotky

mm, N, MPa, t (tuna), s; hustota oceli 7,85·10⁻⁹ t/mm³, g = 9810 mm/s². Teplo: °C, W, W/m², W/(m·K), J/(kg·K). Moment N·mm, frekvence Hz.

Soubory

  • .fea: projekt (zip: model STEP + vstupní study.json + výsledky); Ctrl+S uloží.
  • .step / .stp: geometrie z CAD (sestava s názvy dílů, barvami, vrstvami, atributy).
  • Uživatelská knihovna materiálů, knihovna tření, předvolby tisku: %APPDATA%\FEAStudio.
