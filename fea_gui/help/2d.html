2D section analysis

Analyse a 2D section of the parts cut by a plane: axisymmetric (CAX6 – pipes, vessels, flanges, disks), plane stress (CPS6 – thin plates) or plane strain (CPE6 – long bodies). The 2D mesh can be much finer and runs in seconds. Set up in Solve, group 2D section analysis.

Procedure

  1. Supports and loads as in 3D on model faces; they are converted to section edges.
  2. Check compute 2D instead of 3D; choose Problem type, point, axis (cylindrical parts: Axis from cylinder with a cylindrical face selected) and x direction.
  3. The orange preview in 3D shows the section half-plane. Run.
  4. In Results select case 2D: … and the quantity (σθ, σr, σz, von Mises, displacements…).

What is converted

  • Supports (fixed, displacement, symmetry), pressure, force, gravity, rotation → section edges on the selected faces. Bolts, welds, remote supports, heat etc. give an error; no contacts or dynamics.
  • Axisymmetry: x = radius r ≥ 0, y = axial. Loads and reactions are for the full circumference; σθ = hoop stress; axis nodes are restrained radially.
  • Plane problems: forces and reactions per full thickness; plane strain σz = ν(σx + σy).

Results

The 2D mesh appears in the section plane of the 3D window (3D parts transparent) with legend, max / min markers and a probe (click = value). Line plot… and stress linearization work too. The summary lists reactions in section axes and the equilibrium check.

Verified with A1–A5 (Lamé pipe and sphere, plate with a hole, plane strain, rotating disk) within 0.2%; A1 against 3D (V4) 0.1–0.9%: python -m verification.run_all A1 A2 A3 A4 A5.
