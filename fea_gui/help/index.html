FEA Studio – Help

Strength analysis of parts and assemblies: linear statics, contacts and nonlinear analysis, natural frequencies, buckling, dynamics (vibration, random vibration, shock), topology optimization (BESO), load combinations (EN 1990), mechanisms, bolted and welded joints, 3D-printed parts, beam structures (Timoshenko), heat conduction and thermal stress, fatigue (S-N and ε-N). Solver CalculiX, mesher Gmsh, Exudyn for mechanisms. A few functions are available only through the MCP server or the Python API, not in this window – see below.

Getting started

  1. Examples with a guided tour (fastest): Example 1 – printed bracket, Example 2 – steel + print assembly, Example 3 – flange joint (VDI 2230), Example 4 – welded boom, Example 5 – electronics heat sink. The tour opens the example and explains each step – Examples and tour.
  2. Testing: seven problems with known results – Testing the program.
  3. Your own model: Ctrl+O, a STEP file from CAD (Fusion, Onshape, SolidWorks…), then the phase tabs left to right. Optional analyses (3D printing, Contacts, Beams, Motion, Heat, Dynamics, Fatigue) are added with + after the step tabs (or View → Optional workflow steps).

Tip: F1 = help for the element under the cursor or the current step; Shift+F1 = interactive “What's this?” mode. Language (🇨🇿 Čeština / 🇬🇧 English) and appearance: View menu.

Workflow (phases and steps)

Five phases group the steps: Model (Model, Materials, 3D printing), Assembly (Joints, Contacts, Beams), Conditions (Supports, Motion, Heat, Loads, Dynamics), Calculation (Mesh, Solve), Results (Results, Fatigue). Steps of a phase are tabs above the right-hand panel. A new study shows eight core steps; others activate by study content or with +. Panels have collapsible sections. Step dot: green = done, orange = warning or in progress, red = required input missing, gray = not used. The study tree (top right) shows the same; click an item to open its step.

What the program computes and what it does not

  • Linear: elasticity (small deformations, isotropic and orthotropic / printed), superposition of load cases, fatigue, heat conduction and thermal stress, bolts as preloaded beams, welds as solids, beams (Timoshenko), 2D section, shells, natural frequencies, linear buckling, EN 1990 combinations (STR/GEO, EQU, SLS).
  • Nonlinear and advanced (no superposition; always CalculiX): contact (separation, friction, interference, compression only; perfect heat conduction across closed pairs), bolted-joint interfaces as contact (opening, slip), large deformations, topology optimization (BESO with sensitivity filtering and penalization), step sequence with prescribed motion (force–travel curve).
  • Dynamics: harmonic and transient response, random vibration, shock, sine sweep and spectral fatigue by modal superposition (linear model, no contact), added mass.
  • Mechanisms: rigid-body kinematics and dynamics (Exudyn) – joint reactions, drivers, friction, animation, transfer of an instant or the whole history to FEA; optionally flexible bodies (Craig–Bampton) and body contact (Chrono module).
  • Calculators without FEA (Tools menu): beams, friction, Hertzian contact, press fit, snap-fit, mechanisms, damping from measurement, drop – see Controls.
  • Only via the MCP server / Python API (not in this window): material plasticity (bilinear and multilinear hardening – material property plastic, e.g. custom_props of fea_materials_assign) and its assessment (EN 1993-1-5 Annex C plastic strain, ASME VIII-2 local failure – fea_plasticity_assess); submodeling (fea_core.submodel, Python API only); thermal contact conductance (ContactPair.conductance) and radiation between faces in a cavity (CavityRadiation) – Python API / study file only; measured ε-N parameters (FatigueSettings.en_params); implicit dynamics of a step sequence with contact (LoadStep.dynamic, Python API / study file only). See Automation.
  • Not included: modal (superposition) dynamics with contact, velocity-dependent friction in FEA contact (Coulomb only), gyroscopic effects and spin softening in the Campbell diagram.

Note: stress above yield in a linear analysis is not real – it only means yielding starts (real plastic deformation needs a plastic material – MCP / Python API). Peaks in sharp inner corners, at edges of fixed supports and under point forces are singularities (they grow with refinement; the maxima table marks them). Contact stiffness K and friction μ are estimates, damping has sensitivity ±50 %: check results by sensitivity.

Units

mm, N, MPa, t (tonne), s; steel density 7.85·10⁻⁹ t/mm³, g = 9810 mm/s². Heat: °C, W, W/m², W/(m·K), J/(kg·K). Moment N·mm, frequency Hz.

Files

  • .fea: project (zip: STEP model + input study.json + results); Ctrl+S saves.
  • .step / .stp: CAD geometry (assembly with part names, colours, layers, attributes).
  • User material library, friction library, print presets: %APPDATA%\FEAStudio.
