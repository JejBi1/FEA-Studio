Print detail (voxels)

The 3D printing model (shell + infill) does not see single beads. Voxel detail recalculates a small region around a critical place from the beads: perimeters, top / bottom layers, infill and thin regions set in the print settings. It uses hex8 C3D8I elements with solid extrusion material in the bead axes; boundary displacements come from the whole part. Open it in Results with Print detail (voxels)… (printed parts only).

INDICATIVE: bead paths come from the print settings, not slicer G-code, and boundary conditions from the homogenized model. The minimum at an integration point falls with refinement (voxel steps and bead corners are singularities); use the element average and the 1st percentile.

Procedure

  1. Region centre: Lowest safety factor, Click in 3D, or coordinates. “automatic” = found during the analysis.
  2. Size in print axes (default 6 × 6 × 4 mm), margin (carries boundary conditions, not evaluated), resolution w/2 (voxel = half the line width) or w/4 (~8× more voxels), load case, element.
  3. Estimate size: voxel count, equations, memory, time. “NOT POSSIBLE” above 1.5 million equations or 80 % of free RAM. The region box is orange in 3D.
  4. Run detail runs in the background; Cancel interrupts.

Result

  • Layer section (Layer slider from the build plate): voxel type (perimeter red, layer orange, infill blue, thin region purple), safety factor (Tsai-Wu / Hill), line angle, von Mises, displacement, bead-axis stresses σ11 (along), σ22 (across), σ33 (normal to layers), τ12, τ13, τ23. Bead direction = dashes along the line.
  • Table by load case: safety factor from average element stress (main value), 1st percentile, minimum at an integration point (*), homogenized safety factor in the same region, detail / homogenized ratio, average-stress difference over the region (boundary check, should be small), location of the minimum.

Verified with X1–X4 (homogeneous field, C3D8I bending, P2, path generator): python -m verification.voxel_cases.
